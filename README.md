# Single-Axis-Solar-Tracker

23EEE214 & 23EEE215 - Microcontrollers and Applications, Control Systems based project.

## Project Overview
This engineering mini project combines microcontroller programming and control systems principles to build a single-axis solar tracking system that maximizes solar harvesting efficiency.

## Features
- Single-axis tracking algorithm
- Microcontroller firmware in C
- Basic motor control for actuator

## Prerequisites
- Microcontroller toolchain (e.g., avr-gcc, arm-none-eabi)
- USB programmer/debugger

## Build & Flash
1. Clone the repo:
   git clone https://github.com/adhithya009/1-DSolarTracker.git
2. Build (example):
   make
3. Flash to target microcontroller (use your board-specific programmer)

## Usage
- Connect the tracker to power and sensors, then run the firmware.
